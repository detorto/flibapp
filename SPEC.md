п# Flibusta Reader — Техническое задание

## 1. Обзор проекта

Кроссплатформенное мобильное/десктопное приложение для поиска и скачивания книг из каталога Flibusta через анонимный прокси-бекенд. Сайт flibusta.is заблокирован в РФ, поэтому приложение работает исключительно через промежуточный бекенд, который проксирует запросы к Flibusta.

**Платформы:** iOS, macOS, Android

## 2. Архитектура

```
┌─────────────┐      HTTPS       ┌─────────────────┐     Tor/Direct     ┌──────────────┐
│  Клиентское │  ──────────────► │  Анонимный       │  ────────────────► │  flibusta.is │
│  приложение │  ◄────────────── │  бекенд (API)    │  ◄──────────────── │              │
└─────────────┘                  └─────────────────┘                     └──────────────┘
```

### 2.1 Клиент (мобильное/десктопное приложение)

- **Фреймворк:** Kotlin Multiplatform (KMP) + Compose Multiplatform
  - Единая кодовая база для Android, iOS, macOS
  - Нативный UI через Compose Multiplatform
- **Минимальные версии:** Android 8.0+, iOS 15+, macOS 12+

### 2.2 Бекенд (прокси-API)

- **Язык:** Go или Rust (лёгкий, быстрый, минимальный footprint)
- **Деплой:** контейнер (Docker), легко разворачиваемый на любом VPS/Cloudflare Workers/Fly.io
- **Анонимность хостинга:**
  - Возможность развернуть за Cloudflare (скрытие IP сервера)
  - Поддержка деплоя на платформы, принимающие криптовалюту
  - Нет логирования пользовательских запросов
  - Нет хранения данных пользователей
  - Работа через Tor как опция для подключения к flibusta.is

## 3. Функциональные требования

### 3.1 Поиск книг

| Требование | Описание |
|---|---|
| Поиск по названию | Текстовый ввод, поиск по заголовку книги |
| Поиск по автору | Текстовый ввод, поиск по имени автора |
| Результаты поиска | Список: название, автор(ы), год, доступные форматы, размер |
| Пагинация | Постраничная загрузка результатов |
| Детали книги | Экран с полной информацией: описание, серия, жанры, доступные форматы |

### 3.2 Скачивание книг

| Требование | Описание |
|---|---|
| Форматы | fb2, epub, mobi, pdf, djvu, txt (всё что отдаёт Flibusta) |
| Выбор формата | Пользователь выбирает формат перед скачиванием |
| Прогресс | Отображение прогресса скачивания |
| Сохранение | Файл сохраняется в стандартную папку Downloads / Files |
| Шаринг | "Поделиться" файлом через системный share sheet |
| Открытие | Открытие скачанного файла во внешнем приложении-читалке |

### 3.3 Чего НЕ делаем (вне скоупа)

- Встроенная читалка книг
- Регистрация / аккаунты пользователей
- Избранное / закладки / библиотека (можно добавить позже)
- Push-уведомления
- Рекомендации

## 4. API бекенда

### 4.1 Эндпоинты

```
GET /api/v1/search?q={query}&type={title|author}&page={n}
    → { results: [{ id, title, authors, year, formats, size_mb }], total, page, pages }

GET /api/v1/book/{id}
    → { id, title, authors, year, description, series, genres, formats: [{ type, size_bytes, url }] }

GET /api/v1/download/{id}/{format}
    → binary stream (файл книги)
    → Content-Disposition: attachment; filename="..."
```

### 4.2 Требования к API

- Stateless — никакого состояния между запросами
- Rate limiting — защита от злоупотреблений (по IP, без авторизации)
- CORS — разрешён для всех (в будущем может понадобиться веб-клиент)
- Кэширование — результаты поиска кэшируются на бекенде (TTL 1 час)
- Gzip-сжатие ответов

## 5. Бекенд: требования к анонимности

| Мера | Описание |
|---|---|
| Без логов | Никаких access-логов с IP пользователей. Только агрегированная метрика (кол-во запросов) |
| Без БД | Бекенд stateless, нет базы данных с пользователями |
| Cloudflare | Фронтирование через Cloudflare для скрытия реального IP сервера |
| Tor-выход | Опциональное подключение к flibusta.is через Tor |
| Сменяемость | Бекенд легко переносится на другой хостинг (один Docker-образ) |
| Конфигурация | Единый файл конфигурации или env-переменные |
| Healthcheck | `GET /health` — проверка работоспособности, без раскрытия деталей |

## 6. UI/UX приложения

### 6.1 Экраны

1. **Главный экран (Поиск)**
   - Поле ввода поискового запроса
   - Переключатель: по названию / по автору
   - Список результатов
   - Pull-to-refresh

2. **Экран книги**
   - Полная информация о книге
   - Список доступных форматов с размерами
   - Кнопки: Скачать (выбор формата), Поделиться

3. **Экран настроек**
   - URL бекенда (возможность сменить, если текущий заблокируют)
   - Тема (светлая / тёмная / системная)
   - О приложении

### 6.2 Принципы UI

- Material 3 на Android, нативный вид на iOS/macOS (через Compose Multiplatform adaptive)
- Минималистичный, чистый интерфейс
- Тёмная тема по умолчанию
- Оффлайн-состояние: понятное сообщение об ошибке при отсутствии сети

## 7. Технологический стек

### Клиент

| Компонент | Технология |
|---|---|
| Язык | Kotlin |
| UI | Compose Multiplatform |
| Сеть | Ktor Client |
| Сериализация | kotlinx.serialization |
| Навигация | Decompose или Voyager |
| DI | Koin |
| Загрузки | Ktor + платформенный download manager |

### Бекенд

| Компонент | Технология |
|---|---|
| Язык | Go |
| HTTP-фреймворк | net/http (stdlib) или Chi |
| HTML-парсинг | goquery (парсинг страниц Flibusta) |
| Кэш | In-memory (sync.Map / ristretto) |
| Tor | Опционально: go-libtor или SOCKS-прокси к Tor |
| Контейнер | Docker (alpine-based, <20 MB) |

## 10. Риски

| Риск | Митигация |
|---|---|
| Блокировка бекенда | Сменяемый URL в настройках; несколько зеркал |
